# 合成テスト：記事の確認・差戻し（2026-11-18）

## 対象
- `sandbox-review-actions.gs` と `sandbox-review-actions.test.mjs`
- 既存のGoogle Sheets **テスト専用** `オシスマ_修理事例自動化_合成テスト専用_20261118` のみに限定
- 架空の報告ID `R-20261118-demo0001` のみに限定
- 既存の本番管理シート、回答フォーム、Drive写真、HP、Google投稿は操作しない

## 実装
1. 未承認の架空データとテスト用シートID・名前・ヘッダー・行数をすべて照合する
2. 記事のご相談・修理内容・修理後をモーダルに表示し、**確認済み（テスト）** または **差戻し（テスト）** のみ記録する
3. 差戻し理由は4〜500文字。版番号の楽観ロックに加えてドキュメントロックを利用する
4. HP/Googleの承認列と `approval` フィールドは `draft` を維持し、`publishLog` は触れない
5. 操作後は `sandboxReview` に試験結果を入れ、版番号を一つ上げ、再操作を拒否する
6. 外部AI通信、課金、送信、HP公開、デプロイ関数、メール、Drive参照は持たない

- テストボタンの「確認済み」は本番の `apiApprove` に接続していない。Cloudflareプレビューと最終公開承認は別工程。

## GAS実機検証時の手順と安全条件
1. テスト用スプレッドシートを複製して、現在の状態をバックアップする
2. 新規スクリプトファイルに `sandbox-review-actions.gs` を追加（元の既存ファイルは維持する）
3. **読み取り専用** `oshSandboxReviewRead` を最初に実行する
4. `oshSandboxReviewOpen` で記事内容・確認・差戻しを表示し、許可した合成テストの操作だけを選ぶ
5. `下書き` タブで、**B2=2、C2/D2=draft、E2にsandboxReview** が存在し、本番の公開が変わっていないことを確認する
